# UB freestanding tub — physical wet stack

Plan walls **locked**. Style: tokonoma-card (DESIGN.md §2.7).

```
click floor faucet  →  vertical stream
        │
        ▼
[ landing splash on basin floor ]
        │
   plug seated? ──yes── pool rises to the rim
        │                 if tap still on → fountain veil all around the rim
        │                 wet hue spreads near→far until the whole UB floor
        no
        ▼
   tapered rivulet + beads run to the grate → unseen waste
   floor / towel fade uniformly (extent holds; no receding ring)
```

| Control | Action |
|---------|--------|
| Faucet | Click mixer / lever. On: handle lifts, stream. Off: dry spout. |
| Plug | Click. Seated → lifts to the **west rim**. Aside → seats on the drain. |
| Fill | Rises only when **plugged and faucet on**. At the rim, extra water **spills onto the UB floor**. |
| Floor / towel | Wet **hue** (not a shadow). Near first, then the whole floor. Dry = all fade together. |
